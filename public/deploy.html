Deploy the game contract

One transaction from your own wallet. The operator address (which opens rounds, posts results and relays signed calls) is read from this deployment's /api/info, so SERVICE_SECRET must already be set.

  1. Mainnet, points mode: switch your wallet to Monad (chain 143). Stake is 10 points per call. This is the live game.
  2. Testnet, staked mode (design demo): switch your wallet to Monad Testnet (chain 10143). Stake is 0.01 testnet MON per call, paid by the player. Never deploy this mode on mainnet.
  3. After it confirms, set GAME_CONTRACT in Vercel and redeploy. Then send a little MON to the operator address shown below so it can pay players' gas.
